# 一中易听说

### 让听说作业更容易

#### ***声明：本项目严禁用于考试作弊，或协助他人作弊***

##### 功能：1.获得听说作业答案（在你做完之后）

##### &#x20;          2.帮助其他同学脱离老师监控（包括你自己）

##### &#x20;          3.给其他同学发信息（不能发与考试相关的内容）



##### 使用方法：

##### &#x20;           1.本项目无法独立实现上述功能，其他所列功能实现依赖两个其他项目作者的作品，需自行下载

##### &#x20;           2.将他们放在同一个文件夹下，第一次运行打开“运行我.bat”，并授予管理员权限

##### &#x20;           3.本项目中的默认IP，端口是随便填的（绝对不是真的），根据实际在bat中修改，可以通过“端口查看.bat”获得你的实际端口，也可以把bat的注释取消注释，现场填写（可能费时间）



##### 注意事项：

##### &#x20;             小心玻璃反光，让老师看到你的屏幕，不用担心教师端看到你的屏幕是黑屏，因为在“运行我.bat”运行的同时会让其他几位幸运同学脱离监视，对了，小心信息老师看日志
